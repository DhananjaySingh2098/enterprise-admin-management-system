# Frontend — Enterprise Admin

Angular 22 standalone application. See the [root README](../README.md) for setup and
[docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) for structure.

```bash
npm ci
npm start          # http://localhost:4200, proxies /api → http://localhost:8080
npm run test:ci    # Vitest, single run
npm run build      # production build → dist/frontend
```
